# Project Name: Personal Portfolio Website

## Assumptions:
- This website is designed to work optimally on popular browsers like Google Chrome and Mozilla Firefox.
- It is assumed that the user has internet access to view the live website hosted on GitHub Pages.
- The website was developed using HTML, CSS, and JavaScript to cover basic web development techniques.
- A responsive layout was implemented to ensure smooth viewing on both desktop and mobile devices.

## How to View the Website:
1. To see the website locally, open the `index.html` file directly in your preferred web browser (Chrome, Firefox, etc.).
2. The website is also hosted on GitHub Pages, so you can view it online through the following link:
   https://charishma-09052007.github.io/iss/

## Usage of AI Tools:
- I utilized **ChatGPT** to help clarify HTML, CSS, and JavaScript concepts that I was working on.
- ChatGPT contributed to generating certain parts of the code, such as the website's structure in HTML, CSS for styling, and JavaScript for implementing interactive features like user event tracking.
